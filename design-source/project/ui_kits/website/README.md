# RONANOCfitness — Website UI Kit

## Overview
Mobile-first one-page marketing website. Designed to convert visitors into coaching sign-ups via a central hero form.

## Sections (top to bottom)
1. **Nav** — Logo top-left, mode toggle top-right
2. **Hero** — Full-viewport, centred sign-up form, bold headline
3. **Social Proof Bar** — Stats (clients, years, etc.)
4. **Testimonials** — Scrollable cards
5. **Packages** — Simple pricing/offer cards
6. **FAQ** — Accordion
7. **CTA Section** — Final push with sign-up repeat
8. **Footer** — Minimal

## Design Width
375px (iPhone SE) — scales up gracefully to 480px+

## Components
- `Hero.jsx` — Nav + hero section with sign-up form
- `Testimonials.jsx` — Star-rated testimonial cards
- `FAQ.jsx` — Accordion FAQ component
- `Footer.jsx` — Logo + links + copyright

## Font substitution
Bebas Neue loaded from Google Fonts. If self-hosted version is available, swap the import in `index.html`.
